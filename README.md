# Finanças Zadoni 2026

Este repositório contém um app estático de gestão financeira pessoal com persistência local, meta caixa e gráficos de evolução.

## Arquivo de publicação

O site para GitHub Pages está preparado na pasta:

- `docs/`

## Como publicar no GitHub Pages

1. Acesse as configurações do repositório no GitHub.
2. Vá em **Pages**.
3. Em **Branch**, selecione `main` e como pasta `docs`.
4. Salve.

## Pasta principal do app

- `docs/index.html`
- `docs/app.js`
- `docs/style.css`
- `docs/modules/`
- `docs/netlify.toml`

O app já está pronto para abrir em: `https://<seu-usuario>.github.io/finan-as-zadoni-2026/`
