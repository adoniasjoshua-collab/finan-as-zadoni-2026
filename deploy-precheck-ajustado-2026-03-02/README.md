# Zadoni Variedades

Aplicacao estatica para gestao interna da Zadoni Presentes: vendas, caixa, movimentacoes, ROI de Facebook Ads, recompras, socios e financas pessoais.

## Como rodar

Abra `index.html` no navegador ou publique o repositorio no GitHub Pages. Nao precisa instalar dependencias nem configurar servidor.

## Persistencia

Todos os dados alimentados pelo usuario sao gravados no `localStorage` do proprio navegador. Esta versao nao usa Supabase, API, login ou banco externo.

## Painel principal

O app abre direto no painel financeiro com leitura de lucro real, saldo operacional, ROI de Ads, Top 5 produtos vendidos, Top 5 gastos, Top 5 itens de recompra e alerta de mistura entre caixa pessoal e caixa do negocio.

## Deploy

Veja `DEPLOY-GITHUB.md` para publicar no GitHub Pages.
